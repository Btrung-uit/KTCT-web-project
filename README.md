# MIDAS - Hơn cả một câu chuyện về vàng 🏛️✨

Dự án Website Giáo dục Tương tác kết hợp kiến thức Kinh tế chính trị Mác - Lênin thông qua lăng kính thần thoại Vua Midas.

## 🚀 Tính năng nổi bật
- **Ebook kỹ thuật số**: Trình đọc sách điện tử (13 trang) mượt mà về bản chất của tiền, vàng và các khái niệm kinh tế.
- **Trắc nghiệm tương tác (Quiz Game)**: 20 câu hỏi thử thách kiến thức với giải thích chi tiết, đồng hồ đếm giờ.
- **Bảng xếp hạng (Leaderboard)**: Lưu trữ điểm số và xếp hạng tự động dựa trên Điểm, Số câu đúng và Thời gian.
- **Giao diện chuẩn Cinematic**: Phong cách Hy Lạp cổ đại (Ancient Greek) kết hợp sự sang trọng của tông màu Vàng/Đen, hiệu ứng Glassmorphism & Golden Glow.

## 🛠️ Công nghệ sử dụng
- **React 18**
- **Vite**
- **TypeScript**
- **Tailwind CSS v3**
- **Framer Motion** (Animation mượt mà)
- **Lucide React** (Icons)
- **React Router DOM**
- Lưu trữ dữ liệu với **LocalStorage**

## 💻 Hướng dẫn chạy dự án

### Yêu cầu:
- Đã cài đặt [Node.js](https://nodejs.org/) (phiên bản 18+).

### Các bước cài đặt:
1. Clone dự án về máy:
   ```bash
   git clone https://github.com/Btrung-uit/KTCT-web-project.git
   ```
2. Di chuyển vào thư mục dự án:
   ```bash
   cd KTCT-web-project
   ```
3. Cài đặt các thư viện cần thiết:
   ```bash
   npm install
   ```
4. Khởi chạy máy chủ phát triển (Dev Server):
   ```bash
   npm run dev
   ```
5. Mở trình duyệt và truy cập: `http://localhost:5173/`
